팬 배선

DA04010B12M 2핀: 빨강 +12V, 검정 GND (전원 버튼 뒤 12V 라인)

왜 이 부품인가

  • DC-022 잭은 판매처마다 정격이 0.5~3A로 달라서, 정격이 확실한 54-00311(9A)로 고름
  • 전체 소비 약 30W(폰 25W + 허브 + 팬) → 12V 3A는 한계라 5A 어댑터와 5A 퓨즈
  • PD 모듈은 12V 입력이면 20V 출력은 안 되지만, S20 FE 최대 25W(9V)라 충분 → 승압 모듈 필요 없음
  • 허브는 가격 때문에 Belkin AVC022 대신 DCH-H301로 바꿈. 이 허브의 USB-C는 PD 충전 입력이라 뒷면 USB-C 데이터 포트는 없음
  • 모든 포트가 폰 USB-C 하나를 나눠 쓰므로 PC처럼 포트별 속도가 따로 나오진 않음

가격은 확인하지 않았어요. 어댑터 · 케이블 · 전선은 특정 모델을 고르지 않았으니 규격만 맞추면 됩니다.

주의

  • 배터리가 부풀었으면 이 구성으로 계속 충전하지 않는다
  • 12V는 절대 폰이나 허브에 직접 연결하지 않는다 (반드시 PD 모듈 거침)
  • PD 모듈은 판매처 설명처럼 어댑터를 먼저 켠 뒤 연결
  • 처음 켤 땐 멀티미터로 극성, PD 모듈 출력 확인 후 폰 연결
  • 자석은 보드에서 멀리(모서리) 둔다. 갤럭시는 커버 감지 센서가 자석에 반응해 화면을 끌 수 있어서, 조립 전에 자석을 보드 근처에 대 보고 DeX가 꺼지지 않는지 시험
  • 패널 연장선은 싼 제품일수록 HDMI가 끊길 수 있음. 짧은 것 사용

간단 버전

①~⑤ 대신 USB-C PD 충전기를 허브 PD 입력에 바로 꽂아도 된다. 납땜 없음.
